# Portfolio — Alya Alifia

Portfolio website pribadi Alya Alifia, seorang Frontend Developer.

## 🚀 Tech Stack

- Pure HTML, CSS, JavaScript (no framework — fast & lightweight)
- Responsive design (mobile-first)
- Modern UI dengan animasi smooth

## 📁 Struktur File

```
portfolio-alya/
├── index.html      # Halaman utama
├── style.css       # Semua styling
├── main.js         # Interaktivitas (navbar, animasi, dll)
├── vercel.json     # Konfigurasi Vercel
└── README.md       # Dokumentasi ini
```

## ✏️ Cara Kustomisasi

Edit `index.html`:
- Ganti nama, deskripsi, email, LinkedIn, GitHub
- Update project cards dengan project kamu sendiri
- Tambah/ganti foto avatar

Edit `style.css`:
- Ganti warna di `:root` variables untuk mengubah color scheme

## 🌐 Deploy ke Vercel

1. Push ke GitHub
2. Import repo di vercel.com
3. Deploy! (otomatis, tidak perlu konfigurasi tambahan)
